## 2. SPY 零改善的原因

候选生成器 `scripts/audit-iv-request-scope.py:64` 从当前 `raw_market.option_contract` 选合同；受限 pilot `bifrost-platform-plugin-market-data/src/bifrost_market_data/ingest/long_pilot.py:114` 只校验当前 catalogue，没有逐目标日历史挂牌证明。候选生成器头注虽写明历史适用性待核验，实际 pilot 前置没有完成该证明，导致 96 个无效历史合同日请求。

SPY 四日（08-10…13）的 48 个合同日全部选入后来存在、当日 reference 不存在的到期日。08-10 样本的当前 detail 返回 HTTP 200，而同合同 `as_of=08-10` 返回 404，历史 catalogue 空。与 API 权限、价格复权、限流错误不同：

- 同接口、同 08-10 历史日期，SPY/NVDA/AAPL 三个已知有 bar 的控制合同，历史 detail 和 aggregate 均 HTTP 200，且返回正确 session。
- 97 个目标 aggregate 均 HTTP 200；没有 401/403/429/5xx/transport error，重试不会让未挂牌合同产生历史 bar。
- 15 个原范围 symbol-day 的 planner spot 与 Research 的 as-traded close 一致，未发现用了当前价格或复权价挑历史 strike。
- 主核查 25 组历史 catalogue 都完整。SPY 广泛替代 catalogue 首页截断，未拿截断结果生成执行清单；追加 12 个指定 expiry reference 与 4 个 180–220 DTE reference，全部完整。

180 档还有一项边界：SPY 08-10 当日、±10% 实际 spot、标准合同、180–220 DTE catalogue 为空；03-19 到期日是 221 DTE，不能越过已批准 solver cap220。当日无法按本批规则补齐这档，须保留缺口；未宣布永久无法恢复其他来源。08-11/12/13 的 03-19 到期日为 220/219/218 DTE，历史目录有双侧候选。
