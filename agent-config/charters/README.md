# 各线的章程

每条在跑的线一页：管哪块、对外的口子（按合约形式列明：接口、事件、指令、可读写的存储；评判和测试只对着这些做）、用户和依赖、权限、目标和读数、现状和缺口，末尾列和谁有重叠。
出处：Owner 2026-11-15（值班统筹转述）：每条线的 ownership、权责范围、目标是道和法里的标准和规则，要立住。

- **新开会话先读自己那页。** 文件名是领域目录名。
- 每页由那条线自己写、自己维护。改了就推 `ready/<名字>` 进 main。初稿 2026-11-15 从统筹的共享笔记 `domains/` 收进来。
- 【量】是读到或量到的，【推】是推断或提议。章程里引的 `brain/`、`duty/` 等路径在共享笔记里，不在仓库。
- **重叠还没裁。** 各页末尾「和谁有重叠」里两条线都说归自己、或都说不归自己的地方，由值班统筹汇总、主统筹裁；裁之前不算定。
- **机器不认席位。** 章程只是文字，平台和闸门不按席位放权限。硬边界以根 `CLAUDE.md` §3、§5 为准，章程不能改松。
