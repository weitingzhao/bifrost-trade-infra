| 栏 | 写什么 |
|---|---|
| 哪天 | 他说的那天。括号里「转述」表示来源是统筹转述；「统筹」表示是统筹的话、不是他的 |
| 落在哪 | `` `仓库里的路径`「那一节里能逐字找到的一句」 ``，几处用；隔开。路径从 infra 仓库根算起 |
| 机器强制 | 由哪个程序拦；没有就写「只有文字」 |
| 状态 | 「已落」；「未落：卡在哪」；「不落：为什么」 |
