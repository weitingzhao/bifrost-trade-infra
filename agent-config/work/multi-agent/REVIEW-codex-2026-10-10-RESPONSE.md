## R01 增量 DDL 分类器：采纳

**复现**（platform `7cda6cb`，在干净 worktree 里对 `ClassifyDDL` 跑一次性测试，没有执行任何 SQL）：

| 输入 | 结果 |
|---|---|
| Codex 的 4 条（换行的 `ALTER … COLUMN`、`DELETE … FROM`、不带 `CONCURRENTLY` 的 `CREATE … INDEX`、`SELECT pg_sleep(600)`） | 全部判为可自动放行 |
| `DO $$ BEGIN EXECUTE 'DR' \|\| 'OP TABLE orders'; END $$;` | 可自动放行 |
| `ALTER TABLE orders ALTER /* x */ COLUMN amount TYPE integer;` | 可自动放行 |
| `VACUUM FULL orders;` | 可自动放行 |
| 两条语句对调顺序 | 可自动放行 |
| 对照：同一行的 `DROP TABLE orders;` | 拒绝（正确） |
| 对照：`ALTER TABLE orders ADD COLUMN note text;` | 放行（正确） |

**原因**：按行比较、禁止词清单、默认放行。这三点合在一起，任何没列进清单的写法都会通过。

**现在有没有风险**：没有。`anchor.go` 里的 Owner 指纹还是空的，任何策略都不生效。Owner 生成密钥并签策略之后才会打开。

**已做的止血**（收紧，任何人可做）：`agent-config/release-policy/template.json` 的 `additive_ddl` 改成 `false`，`test_release_policy.py` 改成断言它保持关闭。效果：命中 DDL 路径的发版一律等 Owner，和 W-42 之前一样。

**修法**（W-55，派 Cursor）：按 Codex 的建议改成允许清单，不补禁止词。
- 先把文件切成语句（认注释、字符串、美元引号），再逐条匹配少数几种允许的形状：`CREATE TABLE`（不带 `AS`）、`ALTER TABLE … ADD COLUMN`（可空，或带常量默认值）、`CREATE [UNIQUE] INDEX CONCURRENTLY`、`COMMENT ON`。
- 其他任何语句、切不出来的文件、模板或程序生成的 SQL：转人工。
- 前后对比按语句做，删掉、改写、换序都转人工。
- 引擎层加测试：分类失败时发版回到等 Owner。
- 上表每一条都进回归测试。

**独立复核**：W-55 完成后交 Codex 复现和回归审查，通过了才把 `additive_ddl` 改回 `true`。

**结果（2026-10-10 12:13）**：三轮修复，三次独立复核都判「不成立」（`reviews/codex-2026-10-10-w55-round{1,2,3}.md`），最后一轮的反例是运算符把行注释的起始符吞掉，让一条全表删除被当成未改写。按第三轮前定的止损线放弃文本分类的做法，`additive_ddl` 保持关闭，分支不合并。锁等待、表重写和旧应用兼容性不在分类器里解决，写进 W-56 的迁移演练。

## R02 自动批准先于发布安全闭环：采纳，作为门槛

Codex 说得对：策略签名正确，不等于发布失败后能自己恢复。现状核对：

- Trade 的 PROD 发布已经逐仓钉 SHA（从 STG run 取）；platform 的 PROD 发布还是 `revision=main`，整 SHA 被预检拦下（TD-295）。
- 镜像用可变标签 `:stg` / `:prod`，回滚要重建旧提交。
- 冻结只在以 release-window 开头的流水线里检查（TD-294）；平台服务账号能改冻结用的 ConfigMap（TD-293）。
- 「健康检查失败自动回滚」写在 ADR §5，还没实现。

**处置**：开 W-56，把下面这组条件定为无人值守 PROD 发布的共同门槛，TD-293 至 TD-295 挂在它下面，不重复开题：

1. 每个入口都遵守冻结；
2. 逐仓固定 SHA（含 platform）；
3. 记录实际部署的镜像摘要，部署按摘要引用；
4. 保留上一版已验证的产物，回滚不重建；
5. 独立于发布者的失败检测和回滚；
6. platform 自己升级失败时由带外操作面回滚。

**要 Owner 定的一点**：在这六条完成之前，策略里要不要先不列两条 PROD 流水线。我的建议是先不列：密钥照常生成，策略先覆盖 research 和插件构建；PROD 发布暂时仍由你点批准，等 W-56 验收后再加进策略。代价是你退出 PROD 发布这件事要晚一些。
