## A

**A1 锁什么时候释放**：全改。
- 规则：锁挂在持久的发布操作上，只在 succeeded、rolled_back、stopped_clean、abandoned 四种终态释放（第 119-123 行）。
- 只要操作不在终态，就占着计划里的全部车道和资源；租约过期只把它标成 orphaned（第 125-130 行）。
- run 终态不等于操作终态：pin-sync 超时那一步记 uncertain；发布记录器跳过失败的 run，所以操作跟踪不依赖它（第 128-130 行）。
- 期限：租约单次续期最长 60 分钟，操作另有总期限；到期进入 stuck，锁照旧占着，并冻结该应用（第 131-134 行）。
- 用例：S2「平台和 workers 同时停掉、跨过 TTL 后另一个应用请求同一个库的独占锁被拒」（第 481 行）；S3「run 已终态而 Argo 仍在同步，第二次发布被拒」（第 496 行）；失败模式表第 338-339 行。
