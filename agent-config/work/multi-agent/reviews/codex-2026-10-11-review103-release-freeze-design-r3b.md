- **P1 — §3.2，metadata 扫描器与 oracle 的语言不一致。[document]** 具体字节：`{"apiVersion":"release.bifrost.io/v1","kind":"FreezeList","metadata":{"resourceVersion":"1","resourceVersion":"2"},"items":[]}`。扫描器只要求 metadata 有 1 或 2 个成员、必须有 resourceVersion、键限于 resourceVersion/continue；“四个键各一次”明确约束的是顶层。按这些条件扫描，上述正文可接受；按后文 oracle 的 R、CR、RC 三种形态扫描，则拒绝。两侧无需使用通用 JSON，也能产生不同二进制判定。“重复键构不成问题”的声明没有补上扫描器中的检查。最小修改：把 metadata 的扫描规则直接写成恰好 R、CR、RC 三种成员序列，与 oracle 同源于这个定义；不能由 oracle 默默补充规范。这是有具体字节见证的定义歧义，达到本轮停线条件。
